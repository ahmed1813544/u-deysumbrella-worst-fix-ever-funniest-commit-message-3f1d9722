Entry for the make.fun bounty [Worst Fix Ever: Funniest Commit Message](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722).

`main.py` writes a single commit message — one line, for a bug fix that made everything worse — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Stdlib only, deterministic: the same bytes every run.
